# Mission

The CeloHT dApp exists to make CeloHT's three permanent pillars —
Education, Agent Network, and Reforestation — usable through a single,
open-source application connected to a Valora-compatible wallet.

It is not a product in its own right, separate from those pillars. Every
feature traces back to one of them:

| Feature                                       | Pillar                                       |
| --------------------------------------------- | -------------------------------------------- |
| Courses, quizzes, certificates                | Education                                    |
| Agent directory, map, agent registration      | Agent Network                                |
| Project tracking, donations, planting records | Reforestation                                |
| Governance voting                             | Cross-cutting (community input on all three) |

See the flagship repository's
[`docs/mission.md`](https://github.com/celo-ht/celoht/blob/main/docs/mission.md)
for the full mission statement behind the whole CeloHT ecosystem.
