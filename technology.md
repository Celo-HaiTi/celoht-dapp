# Technology

- Next.js static export with TypeScript
- wagmi and viem for Celo wallet/RPC interactions
- Official CeloHT deployment metadata and generated ABIs
- Official `celoht-backend` API client for authenticated and persisted application data
- GitHub Actions for synchronization, lint, typecheck, tests, audit, and build

There is no local Solidity compiler or deployment workflow in this repository. Contract source and contract tests belong to `Celo-HaiTi/celoht-smart-contracts`.
